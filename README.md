# Бухгалтерия — C# WinForms + PostgreSQL

Учебный проект для зачёта (пара 15, вариант **Муратов**). Магазин ведёт учёт клиентов, товаров, складов, счетов-фактур, отгрузок и оплат, контролирует просрочку 20 дней, экспортирует счёт-фактуру и отчёт о просрочках в Excel, строит круговую диаграмму по ставкам НДС.

## Стек

- C# WinForms (.NET Framework **4.7.2**)
- PostgreSQL (запуск в Docker контейнере `my_postgres`)
- `Npgsql 4.1.10` — клиент PostgreSQL
- `Microsoft.Office.Interop.Excel` — экспорт в Excel (требуется установленный MS Office)
- `System.Windows.Forms.DataVisualization` — круговая диаграмма

## База данных (7 таблиц)

| Таблица | Поля |
|---|---|
| Клиенты | `id`, `Название` |
| Товары | `id`, `Название`, `СтавкаНДС` |
| Склады | `id`, `Название`, `Фабричный` |
| Счета | `id`, `Номер`, `Дата`, `КлиентId`, `Сумма`, `Статус` |
| ПозицииСчета | `id`, `СчетId`, `ТоварId`, `Количество`, `Цена`, `Сумма` |
| Отгрузки | `id`, `СчетId`, `ТоварId`, `СкладId`, `Количество`, `Дата` |
| Оплаты | `id`, `СчетId`, `Сумма`, `Дата`, `Статус` |

Строка подключения по умолчанию (см. `DbConnectionHelper.cs`):
```
Host=localhost;Port=5432;Username=postgres;Password=postgres;Database=postgres
```

## Запуск

### 1. Поднять PostgreSQL в Docker
```bash
docker run -d --name my_postgres -e POSTGRES_PASSWORD=postgres -p 5432:5432 postgres
```

### 2. Создать таблицы
Выполнить DDL из `sql/sql_create_оплаты.sql` (и DDL для остальных 6 таблиц, если их ещё нет).

### 3. Открыть в Visual Studio 2022 / 2026 Insider
- `File → Open → Project/Solution → AccountingApp.csproj`
- Убедиться, что в `References` есть:
  - `Npgsql` (через NuGet, уже в `packages.config`)
  - `System.Windows.Forms.DataVisualization` (Framework)
  - `Microsoft.Office.Interop.Excel` (COM → Microsoft Excel xx.x Object Library)
- **Build → Rebuild Solution** (Ctrl+Shift+B)
- **F5** → запуск
